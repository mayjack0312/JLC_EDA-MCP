## 生成与防漏机制

`npm run generate:api` 使用 TypeScript AST 读取官方类型包：

1. 读取 `EDA` 类的公开根属性；
2. 解析每个根属性对应类的 public 方法；
3. 合并方法重载；
4. 保存参数名、类型、可选性、返回类型、说明和弃用标记；
5. 生成直接 MCP 工具和统一白名单目录。

官方类型包更新后运行 `npm install && npm run build` 即会重新生成覆盖清单。

## 安全边界

- MCP 不提供任意 JavaScript 执行工具；
- 统一调用仅接受目录内的 `namespace.method`；
- 命名空间和方法名由生成清单固定，不从用户输入拼接；
- 参数只接受 JSON 可序列化值；
- Bridge 仅监听 `127.0.0.1`；
- 多个 EDA 窗口必须明确选择或使用当前活动窗口。
